# Tasks passadas

Histórico técnico compartilhado, aditivo e imutável. Cada arquivo registra a
decisão, a evidência e o resultado da task concluída, com data no nome
(`AAAAMMDD_TASK-INFRA-NNN-<slug>.md`). Regras que continuam válidas após a
conclusão devem ser refletidas em `context/` no mesmo change set do
arquivamento; o histórico não substitui o contexto atual.
